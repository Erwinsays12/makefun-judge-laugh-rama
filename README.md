## What it does

`main.ts` writes one original one-line joke about office life to `/output/entry.txt`:

> The printer never jams on a draft — only on files called FINAL_v2_ACTUAL_FINAL, which is how I know it can read.

The joke is built on a true office observation — the printer always jams at the worst possible moment, and every "final" file ends up named `FINAL_v2_ACTUAL_FINAL` — with a surprising turn at the end: the printer must be able to read.

## Run

```sh
node main.ts
```

Deterministic: no clock, no network, no randomness. Requires Node 22.18+ (the grader runs Node 22.23.4).
